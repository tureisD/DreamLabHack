# Click-to-correct simulator demonstrations

This is a robot-free demonstration collector for the bundled MuJoCo YAM scene. In the coach **Demos** screen, load a scene, click a fruit, and optionally click a placement target. The simulator turns those clicks into joint controls, records the overhead and two wrist cameras, checks the physical outcome, replays the exported 10 Hz actions, validates the LeRobot dataset with Dream's local validator, and adds the episode to the coach for human review. It does not call Dream inference or submit a FaaS job.

## Run

From `coach/`:

```powershell
uv sync --extra sim
uv run --extra sim teach-task-coach serve
```

Create a local task with one of the exact instructions below, then open **Demos → Click to correct in YAM simulation**. Choose a new scene seed for each example. The coach writes the 10 Hz episode to `COACH_DEMOS_DIR` (or its usual local demos directory), indexes it, and leaves it **unreviewed**. Inspect all three videos and quality findings, then mark it **Keep** before it can enter a FaaS dataset. Use separate seeds and setups for evaluation.

| Goal | Object | Exact task instruction | Status |
| --- | --- | --- | --- |
| Lift | Apple | `pick up the apple` | Physics checked |
| Lift | Banana | `pick up the banana` | Physics checked |
| Place in bowl | Apple | `put the apple in the bowl` | Physics checked |

The common interface handles rendering, object selection, recording, resampling, Dream validation, and coach import. Each goal adapter supplies a motion plan and a physical success rule. For another task, add its object and goal logic to `click_to_correct.py`, expose it in the service's `supported` list and UI, then verify it across scene seeds and exported-action replay. A task like folding towels cannot be generated by these three adapters. The coach rejects unsupported objects, misplaced clicks, and task instructions that differ from the selected adapter.

These episodes are scripted **simulator** trajectories. Passing a simulator goal check establishes neither Dream-1 performance nor transfer to a physical YAM. Run held-out model trials and the coach's paired evaluation before making an improvement claim.
